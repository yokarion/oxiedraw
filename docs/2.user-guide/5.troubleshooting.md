---
title: Troubleshooting
description: Common problems and fixes when running OxieDraw.
---

## OxieDraw fails to start or shows a blank window

OxieDraw requires a working **Vulkan** driver. Verify one is installed and
detected:

```bash
vulkaninfo | head
```

If this fails, install your distribution's Vulkan driver package (for example
`vulkan-radeon`, `vulkan-intel` or the NVIDIA driver) and try again.

## Stylus pressure or tilt is not detected

Make sure your tablet is recognised by the system (it should appear under your
compositor's input settings). OxieDraw reads pressure and tilt through GTK's
input stack, so a device that works in other GTK apps should work here.

## Something else

If you hit a bug, please open an issue on
[GitHub](https://github.com/yokarion/oxiedraw/issues) with your distribution,
GPU/driver and steps to reproduce.
