# Documents

## Multiple documents

OxieDraw opens documents in **tabs**, so you can work on several pieces at once
and switch between them.

## Saving

Documents are saved as `.oxiedrawproj` project files, which keep your layers,
masks, adjustments, guides, gradients and history.

- Saving is **atomic** - a failed save can't corrupt an existing file.
- Manual saves keep a rolling set of **numbered backups** alongside the project.
- A silent **autosave** keeps a recovery copy in the background, including for
  untitled documents.

## Reusable components

Turn a group of layers into a reusable **component**, then drop live instances
of it across the document. Editing the component updates every instance.

## Exporting

Export a flattened image (for example PNG) to share your work outside OxieDraw.
