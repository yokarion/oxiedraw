# Canvas Workflow

## Pan and zoom

Pan and zoom to move around a large canvas without changing your artwork.

## Rotation

Rotate the view to draw at a comfortable angle:

- **Shift + pan-drag** rotates the canvas.
- Hold **Ctrl** to snap to common angles.
- The rotator dial in the bottom info bar shows and sets the angle; reset it to
  return to upright.

Rotation is a view setting - it does not alter the pixels.

## Drawing guides

ProCreate-style guides help you keep construction accurate:

- **Symmetry** - mirror strokes live across one or more axes.
- **Grid**, **isometric** and **perspective** guides for layout and construction.

## History

Every edit is undoable. Undo/redo history is saved with the project, so you can
reopen a file and still step back through recent changes.
