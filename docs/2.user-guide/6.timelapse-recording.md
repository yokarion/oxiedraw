# Timelapse Recording

You can record a timelapse of your artwork. The recording is stored inside the
project file, so it keeps growing across sessions.
Recording needs [FFmpeg](https://ffmpeg.org) installed.

## Recording

Recording is **turned off by default**. Click the **camera** button
in the top-right to start. You can stop and start as often as
you like; everything lands in the same recording.

The small arrow next to it opens **Start/Stop Recording**, **Export** and
**Recording Settings**.
**Delete** removes the recording from the project the next time you save.

## Exporting

Choose **Export** from the arrow menu:

- **Format**
  - **H.264 Video** - doesn't keep transparency
  - **Animated AVIF** - opens in browsers and in a lot of image viewers
  - **ProRes Video** - Apple's proprietary visually Lossless that supports transparency properly
  - **PNG Image Sequence** - if you want to just have simple PNG files
- **Frame rate** and **Compression** control the length and file size.
- **Include canvas** adds some space around the artwork
- **Background** sets what shows behind transparent areas. Alpha option is hidden for formats that don't support transparency

## Settings

Recording settings are **saved per project**:

- **Frequency** - how often a frame is taken, from every stroke to every 30 seconds.
- **Skip if no change** - no frames while nothing happens, so breaks don't show up in the timelapse.
- **Canvas scaling** - smaller frames keep the project file smaller.
- **Record frame mid-stroke** - also captures strokes in progress. May cause lag while drawing.
- **AutoStart on project open** - start recording as soon as the project opens.
