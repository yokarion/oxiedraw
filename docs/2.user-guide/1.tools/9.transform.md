# Transform

The Transform tool repositions and reshapes the active layer (or the current
selection):

- **Move** - drag to reposition.
- **Scale** - drag the handles.
- **Rotate** - drag outside the handles.
- **Flip** - mirror horizontally or vertically.

Commit the transform to bake it into the layer, or cancel to discard it.
