# Eraser

The Eraser removes paint from the active layer using the same engine as the
Brush - so tip, size, hardness and dynamics all apply. Use it for clean-up, or
with a soft tip for subtle fades.

::note
On a layer mask, painting black hides and white reveals, which often beats
erasing outright - see [Layers & Compositing](/user-guide/layers-and-compositing).
::
