# Brush

The Brush is OxieDraw's core painting tool. It paints onto the active raster
layer with pressure- and tilt-aware dabs.

## Brush types

- **Procedural brushes** - a round tip with configurable size, hardness, flow
  and spacing.
- **Textured (grain) brushes** - chalk, comics and other grains anchored to the
  canvas, so the texture stays put as you build up a stroke.
- **Realistic brush** - a bristle brush using math ported from Krita, for a
  natural-media feel.

## Dynamics

Brush parameters can respond to input:

- **Pressure** - size and opacity.
- **Tilt** - shape and direction.
- **Speed** - stroke width.

## Stabilizer

A stabilizer smooths the input path for cleaner lines. Higher values let the
brush lag behind the cursor to iron out shake; lower values track more directly.
