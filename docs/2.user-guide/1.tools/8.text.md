# Text

The Text tool adds editable text layers with a Figma-like editing experience.

## Text boxes

- **Auto-width** - the box grows with the text.
- **Auto-height** - fixed width, height grows with wrapping.
- **Fixed** - a fixed box; text wraps and clips to it.

Vertical alignment (top / middle / bottom) controls where text sits in the box.

## Styling

Style per character range - font, size, weight and color can vary within a
single text layer. Fonts used in a document are embedded in the project so it
opens the same way on another machine.
