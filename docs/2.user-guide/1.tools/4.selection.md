# Selection

Selections constrain painting, filling and filters to a region of the canvas.

## Modes

- **Rectangular** - drag a box.
- **Elliptical** - drag an ellipse.
- **Freehand** - draw an arbitrary outline.

## Working with a selection

While a selection is active, every edit is clipped to it. Selections pair well
with masks and adjustment layers - see
[Layers & Compositing](/user-guide/layers-and-compositing) - and can be turned
into a layer mask to make the clip permanent and re-editable.
