# Shapes

The shape tools draw clean vector-guided primitives onto the active raster
layer:

- **Line**
- **Rectangle**
- **Ellipse / circle**
- **Triangle**

Drag to define the shape, then release to commit. Shapes are stroked and/or
filled with the current colors, using the active brush tip for the outline where
applicable.
