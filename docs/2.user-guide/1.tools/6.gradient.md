# Gradient

The Gradient tool fills with a smooth blend between color stops.

## Types

- **Linear** - blends along the drag direction.
- **Radial** - blends outward from the start point.
- **Square** - blends in concentric squares.

## Stops

Drag on the canvas to set the gradient's direction and extent. Edit colors on
the multi-stop bar: add stops, drag to reposition, and click a stop to set its
color from the picker. Stops are saved with the project.
