# Fill

The Fill tool flood-fills a contiguous area with the primary color, starting
from where you click. A tolerance setting controls how far the fill spreads
across neighbouring colors - low tolerance stays within tight edges, higher
tolerance bleeds across softer boundaries.

If a [selection](/user-guide/tools/selection) is active, the fill is clipped to
it.
