# Color & Selections

- **Pick blended colors.** The color picker samples the composited result, so you
  can grab the exact on-screen color even where several layers overlap.
- **Adjust non-destructively.** Reach for an adjustment layer (Hue/Saturation,
  Blur, Stroke) instead of editing pixels - you can retune or remove it any time.
- **Turn a selection into a mask.** Make a selection, then convert it to a layer
  mask to keep the clip editable rather than one-shot.
- **Clip work with a selection.** With a selection active, brushing, filling and
  filters only affect inside it - handy for staying inside tight shapes.
