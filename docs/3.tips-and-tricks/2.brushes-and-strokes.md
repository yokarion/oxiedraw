# Brushes & Strokes

- **Fight shaky lines with the stabilizer.** Turn it up for smooth ink lines and
  long curves; turn it down when you need the brush to track exactly.
- **Use grain brushes for texture.** Chalk and comics grains are anchored to the
  canvas, so overlapping strokes build up a consistent texture instead of
  smearing.
- **Let pressure do the work.** Map pressure to size and opacity for natural
  taper - a light touch for fine detail, more weight for bold strokes.
- **Mask instead of erase.** Painting on a layer mask is non-destructive, so you
  can bring erased detail back later.
