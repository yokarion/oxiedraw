# Development Overview

OxieDraw is a Rust + GTK4/libadwaita + Vulkan app, organised as a Cargo
workspace:

- `oxiedraw-core` - core drawing/document model
- `oxiedraw-ui` - GTK/relm4 UI layer
- `oxiedraw-utils` - shared helpers

This page is the jumping-off point for working on it.

## Building locally

```bash
git clone https://github.com/yokarion/oxiedraw.git
cd oxiedraw
cargo build --release
./target/release/oxiedraw
```

## API documentation

Generate the Rust API docs locally with rustdoc:

```bash
cargo doc --no-deps --workspace
# then open target/doc/oxiedraw_core/index.html
```
