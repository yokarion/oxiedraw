# Development Overview

OxieDraw is a Rust + GTK4/libadwaita + Vulkan app, organised as a Cargo
workspace:

- `oxiedraw-core` - core drawing/document model
- `oxiedraw-ui` - GTK/relm4 UI layer
- `oxiedraw-utils` - shared helpers

This page is the jumping-off point for working on it.

## Building locally

```bash
git clone https://github.com/yokarion/oxiedraw.git
cd oxiedraw
cargo build --release
./target/release/oxiedraw
```

## Git hooks

`.githooks/pre-commit` runs clippy and checks that the changelog turns into valid Flatpak release notes. Enable it once per clone:

```bash
git config core.hooksPath .githooks
```

## Flatpak

`flatpak/build.sh` builds the Flatpak, installs it for the current user and runs the Flathub linter. The SDK is installed on first run. It also needs python3 with `aiohttp` and `tomlkit`, for generating `flatpak/cargo-sources.json` from `Cargo.lock`.

The release notes in the Flatpak metainfo are generated from the changelog by `flatpak/changelog-to-metainfo.sh`. Only dated releases are included, so the `(not released)` section shows up once it gets its tag date.

```bash
flatpak install --user flathub org.flatpak.Builder
./flatpak/build.sh
flatpak run com.yokarion.oxiedraw
```

## API documentation

Generate the Rust API docs locally with rustdoc:

```bash
cargo doc --no-deps --workspace
# then open target/doc/oxiedraw_core/index.html
```
