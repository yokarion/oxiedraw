All notable changes to OxieDraw, newest first. Entries are added as part of
the commit that makes the change, under the topmost `(not released)` heading.
Tagging a release turns that heading into the version and its date.

## Releases

### v0.1.10 (not released)

- Fixed crop inconsistent snapping. Automatic aspect ratio detection when
  entering crop.
- Fixed stutters on panning with pen.
- Fixed laggy pen. Input is now resampled by time, allowing to
  interpolate 133Hz drawing devices on higher refresh-rate monitors.
- Removed double-click on a layer row
- Added Layout editing
- Fixed drawing guides having no effect on the Pattern tool.

### v0.1.9 (2026-09-01)

- Fixed pasting an image bigger than the canvas looses parts that fall outside it.
- Added Pattern tool.
- Added Clipping masks.
- Added Alpha lock
- Project schema v12 records both flags; older files load with them off.
- Redesigned Grouping UI in Layers list.
- The left toolbar set the new tool before running the tool-switch logic, so the
  tool being left was already invisible to it and anything that needs to wind
  down on the way out saw the switch as a no-op.
- Every chrome panel sits on the window color. Now they have `.oxiedraw-chrome`.
- Fixed dragging a row or folder casts a drop shadow and keeps its surface while it
  travels, and the drop animates into place.
- Fixed deleting a layer inside a group and undoing puts it back in that group.
- Transform, filter, fill, shape, gradient and liquify previews now respect
  clipping instead of snapping to it on commit.
- Redesigned Selection tool to work like Weight Paint in blender.
- Filter preview keeps adjustment layers, and filters their mask too.
- Added more logging.
- Removed the obsolete view menu from the top bar.
- Added Frame profiler
- Fixed cloning a group loses or duplicates its children.
- Tests that need a real GPU sit behind a `gpu-tests` cargo feature instead of
  `#[ignore]`.
- CI runs plain `cargo test --workspace`, the same command as locally, instead
  of `nextest`.

### v0.1.8

- Fixed clippy issues.
- Added Liquify tool.

### v0.1.7

- Fixed toasts canceling stylus drag.
- Improved fill tool.
- Fixed transform tool.
- Improved shape correction.
- Improved charcoal brush.
- Fixed layers spread across multiple groups.
- Added new brush: Krita-like charcoal pencil.
- Improved Brush UI: grid picker view, cog shortcut, and
  deferred save/discard in the brush manager.
- Added web-documentation with the user guide, tips and rustdoc API pages.

### v0.1.6

- CI: build and release only on tags, lint and test on branches; marked the git
  workspace safe in the version step and fixed the version it reports.
- Fixed clippy warnings under Rust 1.94.
- Moved the repository and CI from Codeberg to GitHub.
- Better brushes: GPU smudge (bristle and oil presets), pattern and texture
  support in the brush format, and GPU tests covering both.

### v0.1.5

- Added Drawing guides: assistant mode, snapping to guides, and ProCreate-style
  symmetry
- Added Canvas rotation, persisted per document.
- Reworked the serde layer for project files.
- Added touchpad gestures support.
- Blend modes now composite in gamma space
- Fixed folder selection ignores adjustment layers.
- Fixed lag on large canvases with integrated GPUs.

### v0.1.4

- Brush stabilizer is now rate-independent

### v0.1.3

- Stripped the forced `GTK_THEME` from the AppImage hook.

### v0.1.2

- Fixed AppImage icons, bundled font, and Wayland scaling.

### v0.1.1

- Hardened the release publish step so it is idempotent for moved tags and
  re-runs.

### v0.1.0

First tagged release.
