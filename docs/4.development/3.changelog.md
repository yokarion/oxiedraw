All notable changes to OxieDraw, newest first. Entries are added as part of
the commit that makes the change, under the topmost `(not released)` heading.
Tagging a release turns that heading into the version and its date.

## Releases

### v0.1.9 (not released)

- Clipping masks: a layer can be clipped to the one below it, rendering only
  where that layer has alpha, so flats can be shaded without ever painting
  outside the silhouette. Any kind can be clipped, including adjustment layers
  (which then affect their base alone instead of the whole folder). The base is
  resolved by position, so reordering and deleting re-resolve on their own;
  hiding the base hides its whole stack. Ctrl+Alt+G, the layer context menu, or
  a click on the gutter elbow that marks a clipped row and points at its base.
- Alpha lock: paint may change a layer's colour but never its alpha, so a shape
  can be recoloured in place. Applies to the brush, fill, gradient, shapes and
  liquify; the eraser is refused outright, since erasing can only remove alpha.
  Shown as a badge on the layer thumbnail, a toggle beside the blend mode, and a
  chip in the canvas info bar, with a one-time toast the first time a stroke
  lands on nothing. `/`, or the layer context menu. Not applicable to text
  layers, whose alpha is regenerated from their content.
- Project schema v12 records both flags; older files load with them off.
- Layers panel: rebuilt on three tones instead of connector lines. Every chrome
  panel now sits on the window colour, layer rows are drawn in the theme's card
  colour on top of it, and a folder (or an adjustment layer) fills the space
  behind itself and everything it covers in a shade between the two, so the
  surface carries the nesting. A row inside a container paints no fill of its
  own - the container is its surface - so the two no longer stack. Folders keep
  their container when collapsed, and a container inside a container leans
  slightly further toward the foreground so the levels stay apart. 6px of
  padding on all four sides, which makes the row pitch uneven, so row placement
  and hit-testing now share one layout pass instead of assuming a fixed slot
  height. Nesting only insets the left, so the eye and drag-handle keep the same
  x whatever a layer's depth. A dragged row or folder casts a drop shadow, and
  keeps its container surface while it travels instead of going transparent.
  The reorder animation aims at the layout the drop will produce - reparenting
  included - so nothing shifts the moment it lands. Clipping keeps its rod,
  which now runs down into the layer it
  clips to and terminates inside that row rather than hooking back under itself.
  A clip base that is also the active layer no longer doubles up an underline on
  the accent fill.
- Deleting a layer inside a group and undoing puts it back in that group.
  The delete dropped the leaf from the folder tree without recording it, so undo
  restored the layer at the root - losing its clipping along with its place.
  Undo also restores the layer's own clip / alpha-lock flags, and a duplicated
  layer keeps them through redo.
- Every live preview now routes through the clip-aware composite. The transform,
  filter, fill, shape, gradient and liquify previews each decided on adjustment
  layers alone, so a clipped layer previewed as if it covered the whole canvas
  and only snapped back on commit. Fill and shape gained scoped preview paths;
  the rest just needed the routing test widened.
- Selection tool: Blender-style coverage heatmap preview (blue to red) so
  feathered and partially subtracted selections are legible, plus Add, Erase
  and Blur mask brushes with pressure-sensitive build-up and a live outline
  that follows the stroke. Shift no longer forces a 1:1 marquee while it is
  acting as the add modifier, and the marquee mode button shows the shape it
  will draw.
- Filter preview keeps adjustment layers in the composite instead of dropping
  them, and filters their mask along with the layer.
- More logging across startup, document loading and the render loop.
- Removed the obsolete view button from the top bar.
- Performance: frame profiler with a stacked stage breakdown in the F3 graph,
  configurable overlay, cheaper layer thumbnails and tab switching. Cloning a
  group no longer loses or duplicates its children.

### v0.1.8

- Clippy: cleared the pre-existing pedantic failures that kept the lint gate,
  and with it the tagged release build, red.
- Liquify tool: brush-driven local warping of a raster layer with Warp, Twirl,
  Pucker, Bloat, Push Left and Reconstruct over a GPU displacement field on a
  pristine snapshot, so repeated strokes stay a single resample. Mirrors across
  drawing guides, clips to the selection, and bakes one undo step per stroke.

### v0.1.7

- Toasts are drawn inside the canvas instead of as overlay widgets, so they no
  longer cancel a stylus drag or steal input.
- Fill tool: fills carry across anti-aliased outlines instead of stopping at
  the first blended pixel, the threshold can be dialled in by holding and
  dragging after the drop, and pixels plus history land before the reveal
  sweep, which now runs on the frame clock so it cannot starve pen input.
- Transform tool moves the whole panel selection (multiple layers and groups)
  as one rigid unit, with N-target GPU live preview, off-canvas data preserved
  across undo and redo, and adjustment layers previewed live.
- Better shape correction.
- Better charcoal brush.
- Fixed layers spread across multiple groups.
- Krita charcoal pencil: textured brush ported from Charcoal Pencil Thin, with
  dotted-paper grain, pressure-driven texture strength (grainy to solid) and
  size taper.
- Brush UI: grid picker view, cog shortcut, and deferred save/discard in the
  brush manager.
- Documentation site (Docus) with the user guide, tips and rustdoc API pages.

### v0.1.6

- CI: build and release only on tags, lint and test on branches; marked the git
  workspace safe in the version step and fixed the version it reports.
- Fixed clippy warnings under Rust 1.94.
- Moved the repository and CI from Codeberg to GitHub.
- Better brushes: GPU smudge (bristle and oil presets), pattern and texture
  support in the brush format, and GPU tests covering both.

### v0.1.5

- Drawing guides: assistant mode, snapping to guides, and ProCreate-style
  symmetry with real-time mirroring of every dab.
- Canvas rotation, persisted per document.
- Shared `EnumMeta` trait for dropdown enums and an `EffectKind::as_filter_spec`
  bridge.
- Reworked the serde layer for project files.
- Touchpad support: two-finger pan and pinch zoom on the canvas.
- Blend modes now composite in gamma space; folder selection ignores adjustment
  layers.
- Removed dead `EngineState` and `Compositor`, documented the architecture in
  module rustdoc.
- Extracted `DocumentSession::new` wiring behind a `SessionCtx`.
- Shared fullscreen-pass construction across renderer modules.
- Clipped the per-frame present pass to the dab region, fixing lag on large
  canvases with integrated GPUs.

### v0.1.4

- Brush stabilizer is rate-independent: its smoothing is rescaled to an 8 ms
  reference interval, so Ink Pen no longer lags far worse on low-end hardware.

### v0.1.3
