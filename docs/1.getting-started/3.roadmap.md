# Roadmap

The current state of OxieDraw and what is planned next.

- [x] Basic pen and mouse drawing
- [x] Layers
- [x] Basic Raster Filters
- [x] More Drawing tools
  - [x] Shapes
  - [x] Selections
  - [x] Masks
  - [x] Gestures (like in ProCreate)
- [x] Adjustment layers
  - [x] Stroke
  - [x] Blur
  - [x] Sharpen
  - [x] Hue/Saturation/Brightness
  - [x] Curves
- [x] Clipping masks and alpha lock
- [ ] Advanced brush engine
  - [x] Parameters-driven brushes
  - [x] Patterns
  - [x] _realistic_ brush
  - [ ] blur brushes
  - [ ] custom shader/code driven brush
- [x] Text support
- [ ] Vector support
  - [ ] Vector import
  - [ ] Vector basic transform
  - [ ] Vector editing transform
- [ ] Advanced image tools
  - [ ] Object extraction
  - [ ] Photoshop-like patch-tool
  - [ ] Professional color-correction tools
- [x] Canvas
  - [x] Rendering
  - [x] Rotating
  - [x] Guidelines
  - [ ] Flip canvas
  - [x] 8 bit integer per channel
  - [ ] 16 bit integer per channel
  - [ ] 16 bit float per channel
  - [ ] 32 bit integer per channel
  - [ ] 32 bit float per channel
- [ ] Linux Release
  - [x] Binaries and AppImage
  - [x] ARM and Asahi Linux support
  - [x] Flatpak file
  - [ ] FlatHub publish
- [ ] Windows Release
- [ ] macOS Release
